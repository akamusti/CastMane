## Why CastMane?

Many recorders write the `.mp4` index only on clean shutdown — if the app
crashes mid-recording, the whole file is often lost. CastMane is built around
a single principle: **a crash must never cost you the footage.**

> Verified: a recording killed with `kill -9` remains fully playable
> (`h264`, `ffprobe`-checked). See the
> [crash-safety guide](/guides/crash-safety/).
